# 00 · Open questions for the user

Every point the rule files leave unclear or undecided, gathered from their "Unclear or not yet decided" sections,
duplicates merged. Part 1 is what a new world needs settled; part 2 is Barcelona's own loose ends. When a question
is answered, the answer goes into the rule file named and the question comes off this list.
