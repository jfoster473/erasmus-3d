# The rules of *Erasmus 3D* worlds

Every rule the user has given over rounds 1–36 (October 2026), written so that a **new world** — a different city
with its own layout and missions (say Valencia) — can be built to the same standard from these files alone. Each rule
is stated generally, with Barcelona as a short example, and says where it came from (the round, and the user's words
where they exist). Each file ends with **"Unclear or not yet decided"**: questions for the user. All of them are
gathered in `00_open_questions.md`.

**Round numbers**: from round 17 on, as `workshop/journal/DECISIONS.md` numbers them; rounds 1–13 as `workshop/journal/HISTORY.md` numbers them
(HISTORY's 14th–17th rounds are DECISIONS' rounds 17–20).

**How they are kept:** when the user says anything that a rule covers, the rule is updated first (and checked
against the others for clashes), then the work is done. Later words win over earlier ones; the file says which rule
changed. The full why of every decision stays in `workshop/journal/DECISIONS.md`; Barcelona's place-by-place path rules in
`docs/PATH_RULES.md`.
